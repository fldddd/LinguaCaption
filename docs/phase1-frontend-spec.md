# Phase 1 前端规格文档 — F1 ~ F6

## 总览

| 模块 | 名称 | 工时 | 依赖 |
|------|------|------|------|
| F1 | 项目脚手架 | 1h | 无 |
| F2 | 点读界面 | 4h | F1 |

## F1 — 项目脚手架 (1h)

### 目标
Electron + Vite 的 SPA 骨架，Hash 路由就绪，各页面可独立开发。

### 子任务
| # | 任务 | 文件 |
|---|------|------|
| F1.1 | **Hash Router 实现** — `#/watch`（播放器）、`#/point`（点读）、`#/review`（复习/生词本）三条路由 | `router.js` |
| F1.2 | **SPA 壳布局** — 顶部导航栏（Logo + 菜单） + 内容区 `<main>`，导航切换高亮 | `app.js`, `index.html` |
| F1.3 | **Electron main/preload** — 主进程窗口创建、`preload.js` 文件对话框 API 暴露、安全策略 | `main.js`, `preload.js` |

## F6 — 本地存储 (3h)

### 目标
为 F5 生词本和词典缓存提供离线存储，不依赖后端数据库（B6）。

### 子任务
| # | 任务 | 说明 |
|---|------|------|
| F6.1 | **storage.js 封装** | `localStorage` 的 Promise 风格封装，支持 JSON 序列化/反序列化 |
| F6.2 | **生词 CRUD** | `getWords()`, `addWord()`, `removeWord()`, `updateWord()`, `getAllWords()` |
| F6.3 | **词典缓存** | 缓存 `dictionaryapi.dev` 返回结果，有效期 5 分钟 |
| F6.4 | **用户偏好** | 保存音量、字幕字体大小、默认模式等设置 |
| F6.5 | **离线检测** | `navigator.onLine` 检测，离线时自动切到缓存数据 |

### Storage Key 设计
```
linguacaption:vocabulary    → 生词列表 (JSON array)
linguacaption:def:${word}  → 词典缓存 (含 timestamp + data)
linguacaption:prefs        → 用户偏好设置 (JSON object)
```

### 缓存过期逻辑
```
cache = JSON.parse(localStorage.getItem(`linguacaption:def:${word}`))
if cache && (Date.now() - cache.timestamp < 300_000)  // 5分钟
  → 使用缓存
else
  → 重新请求并更新缓存
```

### 验收标准
- [ ] 生词 CRUD 操作完整可用
- [ ] 词典缓存 5 分钟有效期内不重复请求
- [ ] 刷新页面后生词数据不丢失
- [ ] 用户偏好设置持久化
- [ ] 离线模式下生词列表可正常查看
